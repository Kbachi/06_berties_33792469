# Bertie’s Books  (Lab 8)

In this lab I implemented session-based authentication using express-session to add login protection to the Bertie’s Books web application. I configured the session middleware in index.js, including a secret key and a 10-minute cookie expiry, making sure it loads before any routes. When a user logs in successfully in users.js, the app now creates a session by setting req.session.userId, which allows the user to remain authenticated while browsing the site. A redirectLogin middleware was created to check whether a session exists, and this was applied to protected pages such as /users/list and /users/audit, as well as some additional routes for the extension task. I also inspected the session cookie in the browser developer tools to confirm its expiry time, path, and security settings.

Finally, I added a logout route in main.js which destroys the active session and confirms to the user that they are logged out. After this, protected pages correctly redirect back to the login page. All changes were tested locally and then pushed to GitHub before being deployed on the virtual machine, where I confirmed that login, session creation, page protection, and logout all work as intended.
